# ✈️ Flight_Price_Prediction

This repository contains a **Flight Price Prediction** Machine Learning model built using **XGBoost**, and experimented with a **Neural Network** approach as well. The model is developed in **Google Colab** using **Python 3** in a **T4 GPU-based environment**.

---

## 📂 Dataset Information

> **Note:** The dataset used in this project is **not owned** by me and has been utilized strictly for **educational purposes**.

- **Dataset Name:** Goibibo Flight Data  
- **Author:** Aman Sahu  
- **Source:** [Kaggle - Goibibo Flight Data](https://www.kaggle.com/datasets/iamavyukt/goibibo-flight-data)

---

## 🛠️ Tech Stack

- Python 3
- Google Colab (with T4 GPU)
- XGBoost
- Neural Networks (optional approach)
